Design choices (planner discretion, none touches a locked item):

- Cards without a usable `s.pos` get a deterministic default spot: a 3-column grid (card width 360, gap 24, origin 24) starting below the lowest positioned card, with the default height from the line count. Nothing is written until the author moves or resizes something. That first commit freezes every card's current spot into `s.pos`, so unmoved cards never jump.
- Push-apart (D-03):
  - The dropped card stays fixed. Every card it overlaps is pushed by the smallest of right / down / left / up that leaves a 24px gap and keeps x, y ≥ 0, ties in that order. Pushed cards push others (queue).
  - Inputs are sanitised first: non-finite → 0, clamped to the LH_CV limits. Zero-area rects never overlap.
  - The cap is 400 pushes, checked before each pop; the inner loop for the popped card always finishes. After the cap, each card still overlapping moves below the lowest card, and the lowest bottom is recomputed after every such move.
  - Every number in Tasks 1 and 2 comes from a run of exactly this rule: SCRATCH/t1z-rev/push2.mjs.
- Mode is view state, not an undo step. Each position or size change is one undo step (D-04).
- A card move starts only from ⋮⋮ or the header's blank area, chevron included. The header's other buttons (名稱, 字母條, −) and the 字數 span keep their own clicks (checker issue 5).

- In free mode ⋮⋮ keeps Alt+↑／↓ for section order. Arrow-key moving (D-07) is Part B.
