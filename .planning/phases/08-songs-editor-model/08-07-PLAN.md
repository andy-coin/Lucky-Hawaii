## Phase Goal

ROADMAP Goal (verbatim; not in user-story form — surfaced, not invented): 歌詞改以資料模型為準，打字（含注音組字）不再被打斷；可以像 Google Docs 一樣用側邊分頁管理多首歌，並匯出、備份、換裝置還原。

<objective>
JSON backup and restore of everything (EDIT-09): 備份全部 saves all songs, the 保留池 and the settings (never API keys) into one file; 匯入備份 on any device shows what is inside and offers the safe 只加入歌曲 or 全部還原 (which backs up the current data first). Old v1 SAVE files still import as a new song. Broken, foreign, too-new or oversized files only explain the problem and change nothing.

Purpose: ROADMAP criterion 4 (匯出 JSON 備份後，在另一個乾淨的瀏覽器匯入即可完整還原), proven with two browser contexts.
Output: backup build / parse / normalise / apply in js/safety.js, import dialog in js/song-io.js, renamed buttons and banner, songs-backup specs, updated smoke / save-failure specs.

Decisions implemented: E1, E2, E3, E4, E5, F5, F7, F8, F10 (lhBuildBackup / lhApplyBackupReplace in safety.js), F11, UI-SPEC D-09 (danger tokens), D-13, D-14, D-15, D-19, D-20.
Choice recorded for Andy (自主決定): add-only imports keep each song's original createdAt (edge-coverage EDIT-09 ordering), so older imported songs sort among the existing ones instead of always appearing on top; 全部還原 also removes registered settings the backup does not contain, so the result equals the source.
</objective>
