## Phase Goal

ROADMAP Goal (verbatim; not in user-story form — surfaced, not invented): 歌詞改以資料模型為準，打字（含注音組字）不再被打斷；可以像 Google Docs 一樣用側邊分頁管理多首歌，並匯出、備份、換裝置還原。

<objective>
Delete a song safely (EDIT-04 刪除): 🗑 opens a real dialog, an automatic backup is stored before anything is removed, the app never ends up with zero songs, and — so that the dialog's 「可從備份還原」 is true — the settings dialog gets a small 自動備份 list that can restore any automatic backup (F1). Safety copies from before the upgrade are pinned so deletions can never push them out, and restoring an old-format backup resets the schema so the migration runs again.

Purpose: completes ROADMAP criterion 2 (刪除) and closes RESEARCH Open Question 1 / Pitfall 10.
Output: delete dialog + logic, pinned backups, schema-aware restore, automatic-backup list, songs-delete specs.

Decisions implemented: C4, F1, A2 (backups before destructive changes), UI-SPEC D-06 (🗑 placement), D-08, D-09 (tokens from 08-07 used for the destructive button), D-16, D-20.
</objective>
