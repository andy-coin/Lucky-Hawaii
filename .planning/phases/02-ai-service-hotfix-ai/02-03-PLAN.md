## Phase Goal

**As a** 作詞人（Andy 本人，以及瀏覽器裡還留著舊模型設定的使用者）, **I want to** 按下 AI 建議時一定拿得到結果，失敗時看到白話原因, **so that** AI 建議不再因模型下架或額度用完而默默失敗。

<objective>
Turn the tracer's single attempt into the real Worker-side fallback chain (AI-02): per-attempt timeout, status classification, cooldowns, budget, both provider adapters, thinking-token handling and structured all-fail errors; keep old cached pages alive through the legacy `POST /` shim; and make the page show the Worker's plain-language reason instead of a blank, a truncated technical string or an endless spinner.

Purpose: success criterion 2 — 「主模型逾時或回 429／5xx 時，Worker 自動換下一個模型、失效模型自動跳過；全部失敗時使用者看到白話的失敗原因，而不是空白或轉圈不停」.
Output: chain in `worker/src/ai.js`, legacy route in `worker/src/index.js`, `tests/worker-ai.spec.mjs`, failure display in `index.html`, `白話` tests.

Decision IDs (numbering in 02-01-PLAN.md): implements D-06 (legacy compatibility, model only a preference), D-07, D-08 (isolate-memory half; the KV half is plan 02-05), D-09, D-10, D-11, D-17, D-21, D-23, and O-2, O-3 (legacy path: non-allowlisted model → auto), O-9, O-10.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker → Gemini / Groq | upstream responses (status, headers, body) are untrusted input to the chain |
| Worker → browser | everything in a response body is visible to any caller |
| legacy clients → Worker root | any caller can post the old `_provider` body |
