CORRECTION to UI-SPEC §4 (custom-property scoping): UI-SPEC sets `--body-extra` on `body` but defines `--pad-b` on `:root`. A custom property that references another is resolved where it is declared, so `--pad-b` on :root would never see body's `--body-extra`.
