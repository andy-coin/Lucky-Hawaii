## Phase Goal

**As a** 作詞人 Andy（電腦、平板、手機都會用）, **I want to** 在三種裝置上都能完整查韻、寫詞、用 AI 建議，而且縮放不吃邊、大量字卡不卡、手機輸入不被鍵盤擋, **so that** 不管拿哪台裝置都能順手寫出押韻好詞。

(Derived from the ROADMAP Phase 5 goal line; see 05-01-PLAN.md.)

<objective>
Desktop / tablet-landscape side panels push the main card instead of sliding over it (today 86–100px of panel content is cut off and the zoom buttons are covered), and every breakpoint decision follows the live viewport so rotating a tablet never leaves stale panel or batch-panel state.

Purpose: UI-01 on L (寫詞, AI 建議 fully usable on desktop) and the rotation robustness all tiers depend on.
Output: CSS push panels, a px-free syncCenterPanel with inert handling, matchMedia listeners replacing every `innerWidth` / `phone` read.

Decisions (IDs as defined in 05-01-PLAN.md objective): D-02, D-03, D-17 (inert part), CX-6, CX-7, OD-7.
</objective>
