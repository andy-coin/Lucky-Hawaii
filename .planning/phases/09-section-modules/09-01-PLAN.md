## Phase Goal

ROADMAP Goal (verbatim; not in user-story form — surfaced, not invented): 段落變成可拖曳排序、可調整高度的模組，搭配結構化標籤、段落顏色、字數統計與 Undo/Redo；AI 候選詞可以直接拖進歌詞裡。

<objective>
Give every section a structured type (Intro / Verse / Pre-Chorus / Chorus / Inter / Bridge / Outro / Custom) with automatic Roman numbering, without a schema migration: old songs get their type inferred from the label when they are read, new songs and new sections get a sensible type, and backups carry and validate the new fields.

Purpose: EDIT-05's data half. Every later plan in this phase (label button, colors, drag, undo) reads type / custom / color / height and the recomputed label from here.
Output: js/sections-core.js (pure, Node-testable), model wiring in songs.js / safety.js / lyrics.js, ?v=0.96.13, node + browser specs, updated expectations in the specs whose strings change because names are now English.

Decisions implemented: CONTEXT A1, A2, A3, A4, B1 (names), B2 (numbering), B6, G3 (file split + version). Accepted for UAT: old songs' export headings become English type names (A3 consequence, orchestrator decision).
</objective>
