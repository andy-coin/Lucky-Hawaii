## Phase Goal

**As a** 作詞人 Andy, **I want to** 按下 AI 建議時拿到的數量一定夠、造出的詞一定押韻（候選夠就由程式填滿，不夠才造詞且只造一輪，詞庫還在載入時也不會誤造詞）, **so that** 我能快速拿到真的寫得進歌詞的押韻詞。

<objective>
Remove the race between the wordlist download and AI suggestions, make the wordlist cache all-or-nothing per version, then run the Phase 4 gate.

Purpose: PERF-03. Today a press during loading only toasts "try again", a partially loaded wordlist is used silently, and a failed chunk during a version change can pin a mixed V1/V2 cache until the next release.
Output: rewritten js/wordlist.js loader, awaiting flow in js/ai-generate.js, tests/wordlist-cache.spec.mjs, helpers tweaks, phase gate evidence.

Decisions (IDs as defined in 04-01-PLAN.md objective): D-10 (show 詞庫載入中…, await the same promise; DISC-2: reuse #aiLoading), D-11 (old chunks cleared and ver written only with the full new set — implemented as one IndexedDB transaction, which RESEARCH shows is the stronger form of the same order), D-12 (non-200 → [好韻器] log), D-14, D-15, OD-3/A6 (any missing chunk → discard the whole set, retry on next press), OD-7. Not done (RESEARCH optional, Claude's discretion default off): reading WORDLIST_CHUNKS from meta, and using an old cache when offline.
</objective>
