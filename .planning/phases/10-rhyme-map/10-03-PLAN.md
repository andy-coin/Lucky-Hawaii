## Phase Goal

ROADMAP Goal (verbatim; not in user-story form — surfaced, not invented): 寫詞時一眼看出押韻結構：句尾依韻部自動上色、段落韻式統計、可選的句中押韻偵測、點字即查韻——判定一律沿用 Andy 既有的核心押韻演算法。

<objective>
Make the colors trustworthy while writing: never wrong (hidden while stale, pixel-aligned at every size and scroll), never in the way (nothing touched during 注音 composition, no long tasks in a 150-line song), and right in every theme.

Purpose: ROADMAP success criterion 5 (MAP-12) and the "readable, correct" half of MAP-02.
Output: staleness rule, theme observer and geometry hardening in js/rhyme-map.js; CSS for rm-stale; tests/rhyme-map-perf.spec.mjs; alignment, composition, cache and contrast specs.

Decisions implemented: CONTEXT A5, B1, B2, B3, F1, F2, F3, G1 (rem, themes, reduced motion), G2. UI-SPEC D-02, D-04, D-05, D-06 (accepted override: one class toggle on the mirror root during composition, zero childList mutations — orchestrator decision), D-22. Planner choices (recorded for UAT in 10-08): RESEARCH's pixel-verified geometry recipe (shared CSS selector + textarea offset box + scrollbar padding) instead of UI-SPEC D-02's copy-computed-style recipe; DOM order instead of z-index 0 / 1 for stacking; a theme / settings repaint covers every section in one pass (no viewport-lazy repaint — measured cost is a few ms).
</objective>
