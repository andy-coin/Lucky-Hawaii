# Phase 10 — UI Design Contract（韻腳地圖）

> Visual and interaction contract for Phase 10. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Andy is asleep and pre-authorized "decide grey areas yourself". 10-CONTEXT.md locks A–G. Every choice below that CONTEXT did not lock is tagged **(Claude's discretion)** and listed in section 1 as a **D-xx**, so Andy can veto it by editing this file. Three places differ from a CONTEXT *mechanism* (not its intent) and are marked **Overrides** in section 1: D-10 (letter click becomes a row list inside the stats popover), D-11 (stats open by click only, hover gets a `title`), D-06 (class toggle on the mirror root is allowed during composition). Nothing else contradicts CONTEXT.
> This phase **adds a read-only coloring layer under the section textareas, one header strip, one stats popover, one settings menu button + menu, and one floating selection bar**. It is not a redesign of the lyrics panel: the Phase 9 section module (header, popover, drag, resize, counts, undo) and the Phase 8 shell stay as they are. Phase 11 will move the menu into a settings page and add position / size / color customization; this contract keeps every control it adds replaceable (one menu = one `lhRmMenu` module).
> Reuses Phase 5 (rem, `--hit` 44px, `--sp-*`, breakpoints S ≤ 440 / M 441–900 / L ≥ 901, z-index scale, light / dark / custom themes, `html.kb-open`), Phase 7 (`--action-*`, specific verb + object labels, AA decided up front), Phase 8 (`--danger-*` untouched, `.word-ctx-menu` shell, `lhPlaceMenu`, outline buttons, accent stripe for "active", 4 sizes / 2 weights) and Phase 9 (`.section-menu*` / `.type-row` / `.swatch`-style custom property precedent, `#lhLive`, flash outline, `aria-disabled` rule, non-modal popover rules, gesture exclusivity).
> All UI text is Traditional Chinese (台灣繁體). Simplified Chinese is forbidden.

Mix constants: `end 34`, `orphan 17`, `inner 30` (percent). The hex values appear **only** in the JS constant; the legend swatches and the mirror use `--rm-cN` custom properties.

### 2.2 Contrast of `--text-primary` on the highlight (computed with WCAG relative luminance; tests recompute)

Surfaces: textarea = `--card-bg`. Light theme: text `#2d3748` on `#f7fafc`. Dark theme (default, after `invertColor`): text `#d2c8b7` on `#2d3748`.

| Case | Mix | Light worst of 16 | Dark worst of 16 |
|------|-----|-------------------|------------------|
| End highlight (full) | 34% | **6.96** (id 15); others 7.28–8.75 | **4.52** (ids 1 and 3); others 4.64–6.80 |
| Orphan highlight | 17% | **9.02** | **5.76** |
| Plain text on plain card (reference) | — | 11.44 | 7.24 |

Custom-theme extremes (both palettes, all 32 colors, worst value): white card + black text → 12.66 full / 16.49 orphan; black card + white text → 11.57 / 17.00; cream `#fffaf0` + `#2d3748` → 7.00 / 9.08; navy `#111c31` + `#d2c8b7` → 5.40 / 7.75. Every row ≥ 4.5. The dark default is the tightest case (4.52): **a custom dark theme whose text is dimmer than `#d2c8b7` can fall below 4.5; that is the user's own theme choice (Phase 5 rule) and Phase 11 will expose the intensity.** Palette changes must keep the dark worst ≥ 4.5, enforced by a unit test.

### 2.3 Visibility of the highlight (decorative band, text carries the content)

| | Light | Dark |
|---|-------|------|
| Band vs `--card-bg`, luminance ratio (full) | 1.31 – 1.64 | 1.26 – 1.60 |
| Band vs `--card-bg`, ΔE76 (full) | ≥ 15.4 | ≥ 8.8 |
| Orphan vs `--card-bg`, ΔE76 | ≥ 7.6 | ≥ 4.5 |
| Closest two families, ΔE76 (full) | 6.1 (ids 9 / 10) | 7.1 (ids 10 / 11) |

A band is a washed fill, so luminance ratios are low by design; the information in the band is *grouping*, which the letters, stats and legend repeat as text. The dark orphan (ΔE 4.5) is deliberately faint ("孤句") and is on the Human check.

### 2.4 Non-text contrast of the underlines (inner rhyme and header-strip letters)

Underline color = `color-mix(in srgb, var(--text-primary) 30%, var(--rm-c))`. Against `--card-bg`: light ≥ 3.53, dark ≥ 3.09 (WCAG 1.4.11 ≥ 3). Closest pair ΔE76 11.6 (light) / 13.6 (dark).

## 4. Header Strip and Stats Popover (MAP-04)

### 4.1 Strip

See D-09. Letter assignment (C1): within a section, the first rhyme seen = A, next new = B, …; "same rhyme" follows the current mode (寬韻: same family; 嚴格: same 韻母); a line with no rhyme = `-`; blank lines are skipped. Tail = the effective tail after punctuation / whitespace trimming and particle skipping (E1).

### 4.2 `#rhymeStats` content (top to bottom)

| Block | Spec |
|-------|------|
| Title | `1rem/700`: 「韻腳統計：{名稱}」 (section name cut to 16 chars + 「…」) |

| Summary | `0.875rem/400`: 「共 {n} 句，押韻 {k} 句（{p}%）」 — `n` = non-empty lines, `k` = lines whose letter occurs ≥ 2 times, `p` = round(k / n × 100). Next line `0.75rem/400 --text-secondary`: 「判定：寬韻」 or 「判定：嚴格」 |
| Rhyme groups | One row per letter that occurs, in letter order: `[letter] [family swatch 1rem] {韻} ×{次數}`, `0.875rem/400`. 寬韻 shows the family label (e.g. ㄤ), 嚴格 shows the 韻母 (e.g. ㄧㄤ). A letter that occurs once gets the suffix 「（孤句）」. Rows are not interactive |

| Close | 「關閉統計」 (`.section-menu-close`) |

Width `min(22rem, calc(100vw - 1rem))`, same shell as D-13, `max-height: calc(var(--app-h) - 1rem)`. Focus: keyboard open → the first line row; pointer / touch → nothing.
