## Phase Goal

**As a** 作詞人（使用者）與維護者 Andy, **I want to** 用更少步驟回報有問題的字詞，並在後台把同一個詞的回報合併批改、一鍵套用到線上修正層、需要時一鍵撤回，累積後用一個腳本寫回 `data/` 再安全清空修正層, **so that** 修正很快就讓線上使用者重新整理就看到，而且不會重複套用或遺失.

<objective>
Tracer for the admin half of FB-03/FB-04: after approving, Andy presses one button and every approved correction goes into the Worker layer; rows show 已上線 and can be revoked with one click. Expansion adds every failure state, the >500 notice, the written state, the effective-readings fix and the backup export button.

Purpose: ROADMAP criterion 3 (「按套用後線上重新整理就看到…按撤回即恢復原狀」) from Andy's side.
Output: apply bar, layer-derived row states, revoke, admin specs through the real Worker code.

Decisions implemented: B3, C2 (revoke by id; status by derivation), C5/E2 copy (「約 1～2 分鐘」), C6, D1 (backup button kept), E3, E6 (admin half), E9 (409 copy), D-14, D-15, D-16, D-20 (撤回 / 重試 labels), D-21.
</objective>
