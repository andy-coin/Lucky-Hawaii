## Phase Goal

**As a** 作詞人（使用者）與維護者 Andy, **I want to** 用更少步驟回報有問題的字詞，並在後台把同一個詞的回報合併批改、一鍵套用到線上修正層、需要時一鍵撤回，累積後用一個腳本寫回 `data/` 再安全清空修正層, **so that** 修正很快就讓線上使用者重新整理就看到，而且不會重複套用或遺失.

<objective>
Tracer for the admin (FB-02): the admin page authenticates with the X-Admin-Key header, merges reports of the same word + reason into one row, and approves or rejects all members with one click. Expansion adds the filter row, select-all and batch 核准 / 駁回 with D-12 defaults, all empty/loading/error states, and removes every template-built inline handler (B5) with an XSS proof and a phone layout pass.

Purpose: ROADMAP criterion 2 (「同一個詞的多筆回報合併成一列，可勾選多筆一次核准或駁回」).
Output: rewritten admin rendering (groups, filters, batch bar), delegated actions, tests/admin.spec.mjs.

Decisions implemented: B1, B2, B4 (admin half), B5, E5 (admin notice), D-11, D-12, D-13, D-17, D-18, D-20 (admin labels), D-21. The 套用 / 已上線 / 撤回 parts (B3, C6, D-14…D-16) come in 07-07; this plan's status derivation already takes a layer argument that stays empty until 07-07 loads it.
</objective>
