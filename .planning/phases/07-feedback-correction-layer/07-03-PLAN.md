## Phase Goal

**As a** 作詞人（使用者）與維護者 Andy, **I want to** 用更少步驟回報有問題的字詞，並在後台把同一個詞的回報合併批改、一鍵套用到線上修正層、需要時一鍵撤回，累積後用一個腳本寫回 `data/` 再安全清空修正層, **so that** 修正很快就讓線上使用者重新整理就看到，而且不會重複套用或遺失.

<objective>
Finish the site half of C4: character-reading corrections from the layer reach the rhyme index the same way the base override file does, and the site stays fully usable when the Worker is missing, slow, broken or offline.

Purpose: ROADMAP criterion 3 for 字庫 corrections (hide/remove/fix/add a reading) and the 「抓不到就略過、不擋畫面」 rule.
Output: two-stage applyRhymeDictOverrides, robustness and ordering specs.

Decisions implemented: C4 (rhymeDict half + failure handling), E2 (no cache bypass).
</objective>
