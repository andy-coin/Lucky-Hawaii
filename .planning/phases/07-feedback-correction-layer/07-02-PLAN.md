## Phase Goal

**As a** 作詞人（使用者）與維護者 Andy, **I want to** 用更少步驟回報有問題的字詞，並在後台把同一個詞的回報合併批改、一鍵套用到線上修正層、需要時一鍵撤回，累積後用一個腳本寫回 `data/` 再安全清空修正層, **so that** 修正很快就讓線上使用者重新整理就看到，而且不會重複套用或遺失.

<objective>
Complete the Worker side of the correction layer on top of the 07-01 tracer: every admin action becomes the right entry, the replay semantics are pinned by a shared vector file (the contract the Python write-back must match), and the layer can be revoked by id, cleared by id after write-back, read by the admin with its key, and protected against stale writes and busy KV. The admin report list also stops silently losing reports past 1,000 keys.

Purpose: FB-03 (all action types), FB-04 (revoke on the Worker), FB-05 prerequisites (admin.json, clear, vectors), FB-02 support (E5 list).
Output: full corrections.js, vectors fixture, revoke/clear/admin.json routes, /reports.json cursor loop.

Decisions implemented: C2, C6 support (count in responses), E4, E5 (Worker half), E6, E9 (rev/baseRev 409), plus the CONTEXT C2 revoke rule 「撤回＝依 id 從修正層移除，來源回報回到已核准未套用」 by derivation (no report write).
</objective>
