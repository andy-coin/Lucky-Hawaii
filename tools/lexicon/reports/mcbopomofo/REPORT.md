## 誤刪怎麼救回

在專案資料夾執行（把「詞」換成被誤刪的詞，可一次寫多個）：

```
python3 -B tools/lexicon/build.py rescue 詞
```

它會把詞加進 `tools/lexicon/rules/keep.json`（之後每次重建都一定保留），並印出可以貼進 `data/wordlist-overrides.json` 的 `added` 裡、讓網站立刻看到這個詞的那一行（`{"w":…,"z":…,"p":…}`）。執行 `npm run lexicon:build` 之後，詞就回到詞庫包裡。

完整的被刪詞清單（每行一個詞，含原因）在同資料夾的 `removed.ndjson`。
